# TG 下载器

本地运行的 Telegram 浏览 / 下载工具，界面做成了和 Telegram 桌面版差不多的样子。
**最全**：评论区、禁止保存的频道，全都能下。**最快**：15 MB/s。

## 为什么用它

别的工具只能命令行盲下，而且基本都漏评论区 —— 可很多频道的资源就发在评论里。

这个是：像用 TG 一样翻，点开就能看，看中哪条下哪条。

## 能下什么

| | 支持 |
|---|---|
| 帖子正文的媒体 | ✅ 图片、视频、动图、文件、音频、语音、视频消息、贴纸 |
| **频道评论区** | ✅ 单条评论、某条帖子的全部评论、整个频道的所有评论 |
| 相册 | ✅ 自动合并成一条，整组一起下 |
| 文字记录 | ✅ 导出 `聊天记录.txt` 和结构化的 `messages.jsonl` |
| 开了「禁止保存内容」的群 / 频道 | ✅ 走官方 MTProto 接口，不受客户端那层限制 |
| 整个群 / 频道 | ✅ 可按类型、大小上限筛选 |

从单张图到整个频道的全部内容 + 所有评论，想下多少下多少。

## 速度：15 MB/s

单文件 8 路并行，比常规写法快 **10 倍**。

| 并行路数 | 速度 |
|---|---|
| 1 | 1.4 MB/s |
| 4 | 7 MB/s |
| **8（默认）** | **15 MB/s** |
| 24 | 12 MB/s |

- 在线播放预取 8 段，首字节 0.2 秒，点开就播
- 下载和播放共用 16 路预算，一边下一边看也不卡
- 同一个文件重复发多遍，只存一份
- 已下过的自动跳过，断了接着下，限流自动等

## 在线预览（不用先下载）

- 图片 → 看大图，← → 翻页
- 视频 / 动图 → 直接播放，能拖进度条
- 音乐 / 语音 → 顶部播放条，换聊天也不停
- PDF / txt → 直接看（txt 自动识别 UTF-8 / GBK）
- 已经下载过的直接读本地文件，更快

## 浏览体验

- 聊天列表：头像、最后一条消息、未读数，可按 私聊 / 群组 / 频道 / 有评论区 / 禁止保存 筛选
- 消息气泡、相册宫格、回复引用、转发来源、链接预览卡片、帖子下方按钮
- **链接能点着跳**：t.me 链接跳到对应频道 / 消息 / 评论，@用户名、#话题、回复引用都能跳
- 聊天内搜索；Esc 或侧键返回

## 安装

1. 装 [Python 3.10+](https://www.python.org/downloads/)（安装时勾上 *Add Python to PATH*）
2. 去 <https://my.telegram.org> → **API development tools** 建一个应用，记下 `api_id` 和 `api_hash`
3. 复制 `config.example.json` 改名为 `config.json`，填进去：

```json
{
  "api_id": 1234567,
  "api_hash": "你的 api_hash",
  "proxy": ""
}
```

`proxy` 留空会自动探测（直连 / 系统代理 / Clash、v2rayN 常用端口），
也可以写 `"socks5://127.0.0.1:7890"` 或 `"http://127.0.0.1:7890"`。

## 运行

双击 **启动.bat**（首次会自动装依赖），或者：

```bash
pip install -r requirements.txt
python app.py
```

第一次弹二维码，用手机 Telegram 扫：**设置 → 设备 → 连接桌面设备**。只需登录这一次。
关掉窗口程序就退出。

## 怎么下

| 想下什么 | 怎么做 |
|---|---|
| 单个文件 | 点它角上的 **⬇** |
| 挑几条 | 右上角 **选择** → 点消息 → 底部 **下载选中的** |
| 整个群 / 频道 | 右上角 **下载全部**（可选类型、大小上限、要不要评论区） |
| 某条帖子的全部评论 | 进评论区 → **下载全部评论** |

左上角 **⬇** 是下载管理（进度、速度、单独停止），**📁** 打开下载文件夹。

## 文件放在哪

```
downloads/群名_ID/
  图片/ 视频/ 文件/ ...     文件名 = 日期_消息ID_原文件名
  评论区/帖子123/           该帖评论里的文件 + 评论.txt
  聊天记录.txt              文字记录
  messages.jsonl           结构化记录，方便二次处理
```

## 技术实现

- [Telethon](https://github.com/LonamiWebs/Telethon)（MTProto）+ aiohttp 本地服务 + Edge/Chrome 应用模式窗口
- 下载用 `iter_download` 的 `stride` 多路分段，各路按偏移直接写同一个文件
- 播放是顺序输出 + 乱序预取：始终保持 8 块在路上，按顺序吐给播放器，支持 HTTP Range
- 并行度用一个全局预算池管理，要么一次拿够要么排队，不会互相等死；播放可以临时超借保证不卡
