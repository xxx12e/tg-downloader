# TG 下载器 · Telegram Downloader

[English](README.en.md) · 简体中文

几乎和 Telegram 桌面版一样的界面，但每张图、每个视频、每个文件都能存到本地。
**评论区、开了「禁止保存内容」的频道，全都能下。下载最高快 10 倍。**

## 为什么用它

市面上的 Telegram 下载工具大多只能命令行操作，看不见内容，只能先全下回来再慢慢筛；而且几乎都漏掉评论区 —— 可很多频道真正的资源，恰恰就发在评论里。

这个工具换了个思路：**先像平时用 Telegram 那样翻聊天、点开就能看，看中哪条再下哪条。** 想整个频道打包带走也可以，一个按钮的事。

## 几乎就是原版 Telegram 的体验

左边聊天列表，右边消息气泡，和你每天用的那个 Telegram 没什么两样：

- 聊天列表有头像、最后一条消息、未读红点，可以按私聊 / 群组 / 频道 / 有评论区 / 禁止保存筛选
- 消息气泡、相册九宫格、回复引用、转发来源、链接预览卡片、帖子下面的按钮，都照着原版做
- **链接点了就跳**：t.me 链接直接跳到对应的频道、消息或评论；@用户名、#话题标签、回复引用也都能点
- 频道帖子下面的「💬 N 条评论」点进去就是评论区，和手机上一样
- 聊天内搜索，Esc 或鼠标侧键返回
- **夜间模式**，左上角 🌙 切换，跟随系统深浅色
- **界面中英双语**，右上角一键切换（日志、下载状态也跟着切）
- **能发消息**：底部输入框，回车发送，支持回复、发图片和文件、删除自己发的

区别只有一个：每个文件角上多了个下载按钮。

## 不用下载也能看

点开就能预览，不想要就不用占硬盘：

- **图片** → 看大图，← → 翻上一张下一张
- **视频、动图** → 直接播放，能拖进度条，边下边播
- **音乐、语音** → 顶部出现播放条，翻页、切换聊天都不会停
- **PDF、txt** → 直接在窗口里看（txt 会自动识别 UTF-8 和 GBK）
- 已经下载过的文件直接读本地，秒开

## 能下什么

| | 支持 |
|---|---|
| 帖子里的媒体 | 图片、视频、动图、文件、音频、语音、视频消息、贴纸 |
| **频道评论区** | 单条评论、某个帖子的全部评论、整个频道的所有评论 |
| 相册 | 自动合并成一条，整组一起下 |
| 文字记录 | 导出 `聊天记录.txt`，外加方便二次处理的 `messages.jsonl` |
| **禁止保存内容的群 / 频道** | 走官方 MTProto 接口，不受客户端那层限制 |
| 整个群 / 频道 | 可以按文件类型、大小上限筛选 |

从「就要这一张图」到「这个频道的全部内容加所有评论」，想下多少下多少。

## 速度：最高快 10 倍

常规下载是一段一段顺着下，大部分时间都耗在等网络来回上。这里把一个大文件拆成 8 段同时拉：

| 并行路数 | 速度 |
|---|---|
| 1（常规写法） | 1.4 MB/s |
| 4 | 7 MB/s |
| **8（本项目默认）** | **15 MB/s** |
| 24 | 12 MB/s（太多反而更慢） |

- **在线播放同样并行**，预取 8 段，首字节 0.2 秒 —— 点开就播，拖进度条立刻接上
- **下载和播放共用总预算**，一边下东西一边看视频也不会卡
- **自动去重**：不少频道会把同一批文件重复发好几遍，按 Telegram 的文件编号识别，重复的只存一份
- 已经下过的自动跳过，中途停了下次接着下，被限流会自动等待
- **再点一次“下载全部”只扫上次之后的新消息**，几万条的大频道不用每次从头翻；想补老帖子下面新增的评论，选“完整重扫”

## 安装

1. 装 [Python 3.10+](https://www.python.org/downloads/)，安装时记得勾上 *Add Python to PATH*
2. 去 <https://my.telegram.org> → **API development tools** 建一个应用，记下 `api_id` 和 `api_hash`
3. 把 `config.example.json` 复制一份改名成 `config.json`，填进去：

```json
{
  "api_id": 1234567,
  "api_hash": "你的 api_hash",
  "proxy": ""
}
```

`proxy` 留空会自动探测（直连、系统代理、Clash 和 v2rayN 的常用端口都会试）。
也可以手动写成 `"socks5://127.0.0.1:7890"` 或 `"http://127.0.0.1:7890"`。

## 运行

双击 **启动.bat**。第一次会在程序文件夹里建一个独立的 `.venv`（不动你电脑上的 Python），
按 `requirements.lock` 装依赖 —— 版本和哈希都锁死，被篡改过的包装不上。以后 lock 文件有更新也会自动补装。

也可以自己装：

```bash
pip install -r requirements.txt
python app.py
```

第一次会弹出二维码，用手机 Telegram 扫一下：**设置 → 设备 → 连接桌面设备**。只需要登录这一次，之后直接进。关掉窗口程序就退出了。

## 怎么下载

| 想下什么 | 怎么做 |
|---|---|
| 单个文件 | 点它角上的 **⬇** |
| 挑几条一起下 | 右上角 **选择** → 点要的消息 → 底部 **下载选中的** |
| 整个群 / 频道 | 右上角 **下载全部**，可以选类型、大小上限、要不要评论区 |
| 某个帖子的全部评论 | 进评论区 → **下载全部评论** |

**每次下载都会先问存到哪个文件夹**，列出你用过的位置，也可以选新的。
同一个文件如果别的文件夹里已经有了，会直接复制过去，不会重新下载。

左上角的 **⬇** 是下载管理，能看进度和速度、单独停某个任务；**📁** 直接打开下载文件夹。

## 文件存在哪

```
downloads/群名_ID/
  图片/ 视频/ 文件/ ...     文件名 = 日期_消息ID_原文件名
  评论区/帖子123/           这个帖子评论里的文件 + 评论.txt
  聊天记录.txt              文字记录
  messages.jsonl           结构化记录，方便二次处理
```

## 技术实现

- [Telethon](https://github.com/LonamiWebs/Telethon)（MTProto 协议）+ aiohttp 本地服务 + Edge / Chrome 应用模式窗口
- 下载用 `iter_download` 的 `stride` 分成多路，各路按自己的偏移直接写同一个文件
- 在线播放是顺序输出加乱序预取：始终保持 8 块在路上，按顺序吐给播放器，支持 HTTP Range 拖进度条
- 并行度用一个全局预算池管理，要么一次拿够要么排队，不会互相等死；播放可以临时超借，保证不卡

## 注意

- `data/` 里存的是你的登录状态，**千万别发给别人、别提交到 git**（`.gitignore` 已经排除了）。
  登录状态用 Windows 自带的 DPAPI 加密保存在 `data/tg.session.dpapi`（老版本的明文 `tg.session` 会自动转过去并删掉）：
  文件被拷到别的电脑、别的 Windows 账户上解不开，所以**换电脑要重新扫码**；但在你这个账户下运行的木马照样能解，来路不明的程序别乱开。
  不想用了就删掉 `data/tg.session.dpapi`，再到手机 Telegram 的**设置 → 设备**里把这个登录踢掉。
- 这个工具只是把你账号本来就能看到的内容存到本地。**下下来的东西自己留着看就好，不要再传播。**
- 频道里发的 **exe / bat / py 等可执行文件，点“打开”不会直接运行**，只会在文件夹里选中它，确认可信再自己双击。
  下载的文件都带了和浏览器下载一样的“来自网络”标记，运行时 Windows 会再提示一次，Office 文档会先进受保护视图。
- 出问题先看 `data/运行日志.txt`。
- 目前只在 Windows 上测过。

## 开发

```bash
pip install -r requirements.txt pytest
python -m pytest
```

不在 Windows 上也能跑，只测 Windows 的几项（DPAPI、文件夹选择框、“来自网络”标记）会跳过；

更新依赖版本的命令写在 `requirements.lock` 开头。
